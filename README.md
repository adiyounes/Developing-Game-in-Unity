# 2D Pirate Game — Unity

A 2D platformer game built in Unity, inspired by Super Mario. Set in a pirate world with custom-built mechanics.

## Highlights

- **Swinger mechanic**   custom rope/grapple system built from scratch
- **Moving boat platform**   dynamic platform that moves and affects player physics
- **2D platformer physics**   jump, run, and navigate pirate-themed levels
